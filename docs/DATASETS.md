# Aegis-Air Datasets

This repo defines authoritative Airline Identity Risk datasets.

Datasets by directory:

- signals/        → aegis_signal
- threat-model/  → aegis_risk_scenario
- demo/          → aegis_demo_case
- dashboards/    → visualization expectations
- api/           → reference contracts only

All datasets are:
- deterministic
- read-only
- schema-governed
- ingestion-ready for STC Intelligence Core
